# Security policy

## Reporting a vulnerability

Please do **not** open a public issue for a security problem. Use GitHub's private vulnerability reporting
("Report a vulnerability" on the Security tab of this repository). Include what you found, how to reproduce it,
and the version or commit you tested.

We aim to acknowledge a report within 3 working days and to agree on a fix and a disclosure date with you.

## Scope

In scope: the code in this repository (the web app, the collectors, the read-only host catalogue, the approval
flow) and the public demo at <https://argus.archidev.ir>.

The demo runs on synthetic data with read-only demo users. Please do not run denial-of-service tests against it.

## Supported versions

Only the latest commit on `main` is supported.
