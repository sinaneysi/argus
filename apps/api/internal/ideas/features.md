# What Argus already does (a short list; replace it with ARGUS_ETC_DIR/ideas-features.md)

- **Incidents**: alerts grouped into incident records with a timeline, acknowledge and resolve, auto-resolve when clear.
- **Root cause reports**: model-written RCA reports linked to incidents, with fix options as proposals.
- **QA intake**: chat reports triaged into QA issues with follow-up questions.
- **Alerts and alert hygiene**: what fires now in each site; noisy, flapping and silent rules.
- **CI/CD**: pipeline watch, failed and stuck pipelines, deploy tracking, findings with occurrences.
- **Capacity**: file systems and hosts that fill up, with days until full.
- **Inventory**: the host estate from the monitoring system, with monitoring and access coverage.
- **Vulnerabilities**: CVE findings by priority, known exploited first.
- **Backups and certificates**: daily checks with age, size and days left.
- **Proposed tasks and the task board**: every automatic suggestion waits for a person to accept it.
- **Agent runs and costs**: every model and job run with status, cost, turns and denials.
- **Ideas**: weekly advisers propose improvements; the operator explores, accepts or rejects them.
