# Writing style

Use this style for every text you write for people: task descriptions, plans, RCA reports, proposals, notices and
chat answers.

## Language

- Write about 80% to ASD-STE100 (Simplified Technical English).
- Write one idea in each sentence.
- Keep a step to 20 words or fewer. Keep a description sentence to 25 words or fewer.
- Use the active voice. Use the imperative for steps ("Restart the service.").
- Use one word for one meaning. Do not change the word for the same thing.
- Do not make noun clusters of more than 3 words.
- Write in English, unless the reader's settings ask for a different language.

## Layout

1. Start with a one-line goal.
2. Give a facts table for hosts, URLs, ports and values.
3. Put the body in numbered sections.
4. Write one action for each checkbox task (`- [ ] ...`).
5. Give the reason for an action as its own sub-bullet that starts with "Reason:".
6. Use numbered lists for steps that have an order.
7. Use tables for values and ports.
8. End with a "Warnings" list. Start each item with a bold lead, for example "**Production:** read only."
9. Do not write long paragraphs.

## Facts and secrets

- Keep every fact, value, command, path and error string exactly as it is.
- Never write a secret value. Write the name of the variable or file that holds it.
