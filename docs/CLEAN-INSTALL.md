# Clean-install backlog

Generated by `python3 -I demo/clean-install/run.py --write` (ADR-0021 D8): `deploy/compose.yml` with an
EMPTY volume and fake GitLab, Jira, Alertmanager and Matrix (`demo/clean-install/stubs.py`). Every page,
API GET endpoint and safe action is classified `works`, `not-configured` (the "Connect X to enable" state)
or `broken`. The gate fails only on a regression: an item that is broken but not listed broken here.
Fixing an item and re-running with `--write` shrinks the list.

Read `works` as "renders without an error": until the data-source registry (ADR-0021 D5) marks a page
`not-configured`, an empty page counts as `works`. An action counts as `works` when it answers below 500
(an empty form is usually refused with 400); a saved request still waits for a host job until the worker
applies it (ADR-0021 D4).
